Productivity boost feature to enhance tab movements. 

Using the shortcut and observing the relative offset, users are able to switch to the desired tab instantly.

## Commands
- `Command + i + offset`: move to the right by offset

- `Command + u + offset`: move to the left by offset

- `Command + b`: move back to the previous tab

## Offset Key Layout
1 2 3 4 5 6 7 8 9

q w e r t y u i o p

a s d f g h j k l

z x c v b n m
